# سكيلز شذى لـ Claude

**المهم تتعلّمي، مو بس تحصلي على النتيجة.**

هون بجمع السكيلز (Skills) اللي بعملها لـ Claude، لكل وحدة عم تتعلّم برمجة أو عم ترجعلها.

## شو هي السكيل؟

السكيل مجموعة تعليمات بتضيفيها لـ Claude مرة وحدة، وبتعلّمه يعمل شغلة معيّنة بطريقة معيّنة، كل مرة. ما بتحتاجي تعيدي الشرح من الأول بكل محادثة.

## ليش هالسكيلز؟

الـAI بيعطيكي النتيجة بثواني، بس الفهم ما بيجي لحاله. هالسكيلز معمولة لتساعدك تفهمي، مش بس تخلّصي:

- **بالعربي:** الشرح بالعربي، والكود بيضل متل ما هو.
- **للمبتدئات:** مش لازم تكوني فاهمة شي من قبل.
- **صغيرة:** كل سكيل بتعمل شغلة وحدة، وبتكفيها دقايق.
- **بتعلّم، ما بتحلّ عنك:** الهدف إنك إنتِ تفهمي.

رح ضيف سكيلز جديدة شوي شوي. حطي ⭐ للريبو لتضلّي متابعة.

## السكيلز

| السكيل | شو بتعمل |
| --- | --- |
| [`codewalk`](skills/codewalk) | بتشرحلك الكود سطر سطر بالعربي، وبتورجيكي كيف البيانات عم تتغيّر بكل خطوة. |

## كيف بضيف سكيل لحسابي؟

1. بـ Claude روحي على **Settings ← Capabilities** وشغّلي **Code execution and file creation**.
2. نزّلي الريبو (الزر الأخضر **Code** ← **Download ZIP**) وفكّي الضغط.
3. من جوّا `skills`، اضغطي مجلد السكيل اللي بدك ياها لملف ZIP، وخلّي اسم المجلد متل ما هو.
4. بـ Claude روحي على **Customize ← Skills ← + ← Create skill ← Upload a skill** وارفعي الملف.

دليل Claude الرسمي: [Use Skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## English

**Shaza's Claude Skills: understand it, don't just get the result.**

A growing collection of small [Claude Skills](https://support.claude.com/en/articles/12512180-use-skills-in-claude) for people learning (or coming back to) code. A skill is a set of instructions you add to Claude once, so it handles a task the same way every time.

These skills are Arabic-first, made for beginners, and each does one small thing. They help you understand rather than doing the work for you. New skills will be added over time.

| Skill | What it does |
| --- | --- |
| [`codewalk`](skills/codewalk) | Walks through code line by line in Arabic and shows how the data changes at each step. |

**Install a skill:** turn on *Code execution and file creation* in **Settings → Capabilities**, zip the skill's folder from `skills/` (keep the folder name), then upload it in **Customize → Skills → + → Create skill → Upload a skill**. In Claude Code, copy the folder into `~/.claude/skills/`.

Ideas and bug reports are welcome in [Issues](../../issues) or on Instagram at [@shaza.techmama](https://www.instagram.com/shaza.techmama/).
